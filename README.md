# 미니맵 감시 알리미 (screen-reader)

메이플스토리 **미니맵**을 지켜보다가 소리로 알려 주는 윈도우용 프로그램입니다.
기능은 둘뿐이고, **각각 따로 켜고 끕니다.**

| 기능 | 무엇을 하나 |
|---|---|
| **1. 룬 감지** | 미니맵에 룬(보라 마름모)이 뜨면 알림 |
| **2. 캐릭터 위치 감지** | 내 캐릭터(노란 원)가 허용 범위를 벗어나면 알림 |

**미니맵 영역은 한 번만 지정하면 두 기능이 같이 씁니다.**
둘 다 **색**으로 찾습니다. 그림을 통째로 대조하지 않아서 맵이 바뀌어도 그대로 씁니다.

---

## 설치

### 1. 파이썬 (없을 때만)

https://www.python.org/downloads/ 에서 받아 설치합니다. **3.9 이상**이면 됩니다.

> 설치 화면 맨 아래 **"Add python.exe to PATH"** 를 꼭 체크하세요.
> 이걸 놓치면 `setup.bat` 이 파이썬을 못 찾습니다.

이미 깔려 있는지는 명령 프롬프트에 `py -V` 를 쳐 보면 압니다.

### 2. setup.bat 더블클릭

가상환경(`.venv`)을 만들고 필요한 패키지를 받습니다. 처음 한 번은 몇 분 걸립니다.

### 3. 실행.bat 더블클릭

끝입니다. 다음부터는 `실행.bat` 만 누르면 됩니다.

> 새 PC 에서 이 프로젝트를 받았다면 `.venv` 는 딸려 오지 않습니다(용량이 커서 제외).
> **반드시 `setup.bat` 부터** 한 번 돌려 주세요.

## 먼저 — 미니맵 영역 지정 (한 번만)

**[영역 지정]** – 화면이 어두워지면 미니맵을 드래그로 감쌉니다.

- 방향키로 1px 이동, `Shift`+방향키로 크기 조절, `Enter` 확정, `ESC` 취소
- 미니맵 **테두리 안쪽**만 잡는 것이 가장 정확합니다.

이 영역 하나를 룬 감지와 캐릭터 위치 감지가 같이 씁니다.
게임 해상도나 창 위치를 바꿨을 때만 다시 지정하면 됩니다.

---

## 1. 룬 감지

**사용** 을 체크하고 **[감지 시작]**. 끝입니다.

룬이 떠 있을 때 **[지금 확인]** 을 누르면 몇 개 잡히는지 기록에 찍힙니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| 이 시간 이상 계속 보이면 알림 | 1.5초 | **오탐을 막는 핵심 값** (아래 설명) |
| 룬이 남아 있는 동안 다시 알림 | 켬 / 30초 | 룬을 먹을 때까지 계속 알려 줍니다 |
| 소리 / 반복 | `sounds/rune.wav` / 2 | 비워 두면 기본 알림음 |

---

## 2. 캐릭터 위치 감지

미니맵 영역 **안에** 허용 범위를 하나 더 그립니다.

```
┌─ 미니맵 영역 (위에서 지정한 것) ────────────┐
│                                             │
│        ┌─ 허용 영역 ─────┐                  │
│        │      ●          │   ← 여기 안에 있으면 정상
│        └─────────────────┘                  │
│                              ●  ← 여기로 나가면 알림
└─────────────────────────────────────────────┘
```

**[허용 영역 지정]** – 미니맵이 **크게 확대된 창**이 뜹니다.
캐릭터가 여기 안에 있어야 정상인 범위를 드래그하세요.
(파란 점선 = 지금 설정된 허용 영역)

미니맵은 화면에서 100px 남짓이라 화면에서 직접 드래그하면 손이 떨립니다.
그래서 **확대된 창 안에서** 고르도록 했습니다.

미니맵 영역을 **크기가 다르게** 다시 지정하면 허용 영역은 지워집니다. 다시 그려 주세요.

| 항목 | 기본값 | 설명 |
|---|---|---|
| 허용 영역 밖에 N초 이상 | 3초 | 점프로 잠깐 스치는 건 넘어갑니다 |
| N초 이상 안 보여도 알림 | 10초 | 맵을 뜨거나 죽은 경우. `0` 이면 안 알림 |
| 돌아올 때까지 N초마다 재알림 | 10초 | 자리를 비운 사이에도 알아챌 수 있게 |
| 소리 / 반복 | `sounds/char.wav` / 2 | 룬과 다른 소리라 구분됩니다 |

아이콘이 여러 개 보이면 **직전 위치에 가장 가까운 것**을 내 캐릭터로 봅니다.
다른 유저(분홍 원)와 겹쳐도 엉뚱한 쪽을 따라가지 않습니다.

---

## 왜 "N초 이상 계속 보이면" 인가

색만 보면 어느 맵에나 잠깐씩 아이콘처럼 보이는 **지형 얼룩**이 있습니다.
샘플 영상 2편(합계 3시간 40분)을 10fps 로 재 봤더니 —

| | 한 번에 얼마나 버티나 |
|---|---|
| 지형 얼룩 | **길어야 0.8초** |
| 진짜 룬 | **3초 이상** (먹을 때까지 몇 분씩 머물기도 함) |

그래서 "한 번 보였다" 가 아니라 **"같은 자리에서 1.5초에 걸쳐 계속 보인다"** 를
조건으로 씁니다. 여기서 재는 건 **실제로 보인 구간**입니다 — 처음 보인 순간부터
마지막으로 **보인** 순간까지가 1.5초를 넘어야 합니다. 그래야 잠깐 반짝한 얼룩이
"아직 살아 있는 셈 치는" 유예 시간 덕에 통과해 버리는 일이 없습니다.

이 하나로 지형 오탐이 사실상 사라집니다.
예전처럼 *배경 학습* 을 하거나 맵을 옮길 때마다 다시 설정할 필요가 없습니다.

잠깐 깜빡이는 건(영상 압축 탓에 자주 그럽니다) 끊긴 걸로 치지 않습니다.
3초까지는 이어진 것으로 봅니다 — 밝은 지형 위에 뜬 룬은 3초에 한두 번씩만
잡히기도 해서 이만큼 여유를 줘야 놓치지 않습니다.

## 샘플 영상 검증 결과

`샘플 영상` 두 편(합계 3시간 40분)을 GUI 와 똑같은 코드로 초당 4번씩 돌린 결과입니다.
알림이 울린 장면은 전부 몽타주로 하나씩 눈으로 확인했습니다.

### 룬 감지

| 영상 | 길이 | 룬 | 찾은 룬 | 오탐 |
|---|---|---|---|---|
| 2026-09-07 | 1시간 58분 | 7개 | **7개** | **0** |
| 2026-09-13 | 1시간 45분 | 10개 | **10개** | **0** |
| 2026-09-20 | 2분 (밝은 맵) | 0개 | — | **0** |

**오탐 0건입니다.** 알림이 울린 장면은 전부 확대해서 눈으로 확인했습니다.

세 번째 영상은 룬이 없는 밝은 맵입니다. 감지 영역이 미니맵 밖으로 조금 넘치는
경우까지 7가지로 돌려 봤지만 전부 0건이었습니다.

그러면서 **그림 대조 방식이 놓쳤던 룬 1건(영상2 54:05)** 을 더 잡았습니다.
밝은 초록 지형 위에 3분 넘게 떠 있던 룬인데, 그림이 배경에 묻혀 대조가 안 되던
경우입니다. 색으로 바꾼 덕을 본 사례입니다.

### 캐릭터 위치 감지

| 영상 | 캐릭터를 찾은 비율 | 알림 | 내용 |
|---|---|---|---|
| 2026-09-07 | 99.1% | 4건 | 허용 영역 이탈 3 + 실종 1 |
| 2026-09-13 | 91.1% | 12건 | 허용 영역 이탈 10 + 실종 2 |

전부 진짜였습니다. 실종 알림은 상점 창이 미니맵을 가린 구간(20초)과
맵을 옮기느라 캐릭터가 사라진 구간(29초 / 123초)에서 났습니다.

다른 유저(분홍 원)가 캐릭터 바로 옆에 붙어 있어도 엉뚱한 쪽을 따라가지 않았습니다.

## 아이콘을 잘 못 잡을 때

게임 해상도나 미니맵 배율을 바꿔서 아이콘 크기·색이 달라진 경우입니다.

**[색 다시 잡기]** – 미니맵이 확대된 창에서 찾고 싶은 아이콘 한가운데를 클릭하면
**색 범위와 크기 조건이 한꺼번에** 그 아이콘에 맞춰집니다. 이것부터 해 보세요.
룬과 캐릭터가 각자 따로 있습니다.

그래도 안 되면 **[세부…]** 에서 직접 만집니다. 되돌리고 싶으면 맨 위의
기본값 버튼을 누르면 됩니다.

| 항목 | 룬 | 캐릭터 | 설명 |
|---|---|---|---|
| 색조 H | 135~155 | 22~38 | OpenCV HSV 기준(0~179) |
| 채도 S | 90~255 | 120~255 | |
| 명도 V | 150~255 | 170~255 | |
| 픽셀 수 | 18~250 | 12~250 | 덩어리 크기 |
| 변(px) | 4~22 | 3~22 | 바운딩 박스 한 변 |
| 가로세로 비율 허용 | 1.6 | 1.6 | 긴 변 / 짧은 변. 납작한 지형 얼룩을 걸러 냅니다 |
| 채움비 | 0.40~1.0 | 0.40~1.0 | 박스 대비 채워진 비율. 마름모는 0.5 근처 |
| 밝은 테두리 비율 | 0.15 | 0.20 | 덩어리 둘레가 밝은지 |
| 흰 테두리 비율 | 0.20 | 0 (끔) | **오탐을 막는 핵심 값** (아래 설명) |

### 테두리 조건 두 가지

미니맵 아이콘에는 흰 테두리가 둘러져 있지만, 아이콘과 같은 색으로 그려진
지형 그림에는 없습니다. 이걸 두 단계로 봅니다.

| | 어디를 보나 | 무엇을 세나 |
|---|---|---|
| **밝은 테두리 비율** | 바운딩 박스 바깥 2px 띠 | 밝은 픽셀 (채도 100 미만, 밝기 140 초과) |
| **흰 테두리 비율** | 덩어리 모양에 딱 붙은 1px 띠 | **흰 픽셀** (채도 60 미만, 밝기 185 초과) |

**흰 테두리 비율이 오탐을 거의 다 잡아냅니다.** 지형 얼룩도 밝은 배경 위에 있으면
'밝은 테두리' 는 통과하지만, 채도까지 낮은 진짜 흰색은 룬에만 있습니다.
띠를 박스가 아니라 **덩어리 모양**에 붙인 것도 중요합니다 — 마름모는 박스 네
귀퉁이가 배경이라, 박스 기준으로 재면 테두리가 묻혀 버립니다.

샘플 영상 2편에서 잰 값입니다 (덩어리 단위, 진짜 572개 / 가짜 41개).

| 조건 | 진짜 통과 | 가짜 통과 |
|---|---|---|
| 밝은 테두리 ≥ 0.28 | 74.5% | **48.8%** |
| 흰 테두리 ≥ 0.12 | 79.0% | **0.0%** |

흰 테두리 조건이 오탐을 막아 주는 덕에 밝은 테두리 기준을 0.15 까지 낮출 수 있었고,
그 덕에 어두운/밝은 지형 위의 룬을 더 잘 잡게 됐습니다.

기본값을 **0.20** 으로 둔 이유는 밝은 맵 때문입니다. 미니맵 지형의 보라 얼룩이
바로 옆 아이콘의 흰 테두리를 빌려 0.16 까지 올라오는 경우가 있었습니다.
영상 3편으로 맞춰 보니 0.20 이 **진짜 룬을 하나도 안 놓치면서** 그걸 걸러 내는
지점이었습니다.

| 흰 테두리 기준 | 진짜 룬 | 지형 오탐 |
|---|---|---|
| 0.12 | 17/17 | 밝은 맵에서 2건 |
| **0.20** | **17/17** | **0건** |
| 0.25 | 15/17 | 0건 |

캐릭터 아이콘은 훨씬 작아서 1px 띠에 흰색이 거의 안 잡힙니다(중앙값 0.04).
그래서 캐릭터 쪽은 `흰 테두리 비율` 을 **0** 으로 꺼 두었습니다.

**[설정 저장]** 을 누르거나 창을 닫으면 `settings.json` 에 저장되고, 다음에 켤 때
같은 영역·설정으로 시작합니다.

## 파일 구성

```
실행.bat / setup.bat     실행 / 설치
main.py                  GUI + 감지 스레드 (미니맵을 한 번 캡처해 둘 다 검사)
detector.py              아이콘 찾기 (색 + 크기/모양 + 흰 테두리)
watch.py                 시간 판정 (몇 초 유지됐나, 언제 알릴까)
capture.py               mss 화면 캡처 (DPI 배율 대응)
region_select.py         화면 드래그 선택, 확대 창(색 찍기 / 허용 영역)
notifier.py              알림음 재생, 기본음 WAV 생성
config.py                설정 저장/불러오기, 기본 색 조건
sounds/rune.wav          룬 알림음 (처음 실행할 때 자동 생성)
sounds/char.wav          캐릭터 알림음 (처음 실행할 때 자동 생성)
tools/analyze_video.py   녹화 영상으로 설정 검증
settings.json            저장된 설정 (실행하면 생김)
```

## 녹화 영상으로 검증하기

GUI 와 **똑같은 판정 코드**(`watch.py`)를 돌리므로, 여기서 나온 사건 목록이
곧 "그때 실제로 소리가 울렸을 횟수" 입니다.

```
:: 룬
.venv\Scripts\python.exe tools\analyze_video.py "샘플 영상\MapleStory 2026-09-07 21-44-38.mp4" ^
    --roi 22,42,178,60 --what rune --dump out\rune

:: 캐릭터 (허용 영역은 --roi 기준 상대 좌표)
.venv\Scripts\python.exe tools\analyze_video.py "샘플 영상\MapleStory 2026-09-07 21-44-38.mp4" ^
    --roi 22,42,178,60 --what char --allow 125,30,36,22 --dump out\char
```

- `--roi x,y,w,h` 영상 안에서 미니맵 위치 (GUI 의 "미니맵 영역"에 해당)
- `--what rune|char` 무엇을 검사할지
- `--allow x,y,w,h` 캐릭터 허용 영역 (ROI 기준 상대 좌표)
- `--fps N` 초당 N장 검사 (기본 4 = 감지 주기 0.25초와 같음)
- `--settings settings.json` GUI 에서 저장한 설정 그대로 검증
- `--dump DIR` 알림이 울린 장면을 모아 `montage.png` 로 저장

`montage.png` 를 열어 전부 진짜였는지 눈으로 확인하면 됩니다.

## 자주 겪는 문제

**룬이 떠 있는데 안 울림**
- **[지금 확인]** 을 눌러 보세요.
  - `1개` 라고 나오는데 소리가 안 났다 → `이 시간 이상 계속 보이면 알림` 을 낮추기
  - `0개` → **[색 다시 잡기]** 로 룬 한가운데를 클릭
- 그래도 안 되면 **[세부…]** 에서 `흰 테두리 비율` 을 0.08 쪽으로 낮추기

**엉뚱할 때 울림**
- 먼저 **감지 영역이 미니맵 테두리 안쪽에 딱 맞는지** 보세요.
  조금이라도 밖으로 넘치면 게임 배경의 보라색이 들어옵니다.
- `흰 테두리 비율` 을 0.25 쪽으로 올리기 (가장 효과가 큽니다)
- `이 시간 이상 계속 보이면 알림` 을 2~3초로 올리기
- `가로세로 비율 허용` 을 1.3 쪽으로 낮추기 (납작한 얼룩을 걸러 냅니다)

**캐릭터 이탈 알림이 자꾸 울림**
- `허용 영역 밖에 N초` 를 5~10초로 올리기
- **[허용 영역 지정]** 으로 범위를 조금 넓게 다시 잡기

**캐릭터가 안 보인다고 자꾸 울림**
- `N초 이상 안 보여도 알림` 을 15~20초로 올리거나 `0` 으로 꺼 두기
- **[색 다시 잡기]** 로 캐릭터 아이콘을 다시 잡기

**영역이 화면과 어긋남**
- 디스플레이 배율(125% 등)을 바꿨다면 프로그램을 다시 켜고 영역을 다시 지정하세요.

**실행.bat 을 눌러도 아무 반응이 없음**
- 대개 `setup.bat` 을 아직 안 돌린 경우입니다. `실행.bat` 이 이유를 알려 주고 멈춥니다.
- `py 는 실행할 수 있는 프로그램이 아닙니다` 가 뜬다면 **파이썬이 안 깔린 것**입니다.
  위 [설치](#설치) 1번을 먼저 하세요.
- 창이 떴다 바로 닫히면 프로그램 폴더의 `error.log` 를 열어 보세요.
  실행 중 오류는 거기에 쌓입니다.
